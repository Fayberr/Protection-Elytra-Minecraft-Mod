# Protection Elytra

Lets you put protection enchantments on an Elytra. Combine an Elytra with an enchanted book at an anvil like with any other armor. The enchantments take effect while the Elytra is worn in the chest slot.

## Features

- Protection, Fire Protection, Blast Protection, Projectile Protection and Thorns can be applied at an anvil.
- Each enchantment can be switched off in the config.
- An option to allow every armor enchantment on the Elytra.
- Settings screen through Mod Menu, using Modern Config if it is installed and Cloth Config otherwise.

## Notes

- Runs on the server. The integrated server in singleplayer works too, and clients do not need the mod to join.
- Requires Fabric API. Minecraft 26.3.
- Config file: `config/protection_elytra.json`.
